❯ how do i open the dashboard                                                   

● You start it from the VS Code terminal, then it opens in your web browser.

  1. Open a terminal in VS Code. Use the menu Terminal → New Terminal, or press
  Ctrl+`  (the key above Tab).

  2. Go to the assignment folder and start the app. Type these two lines,
  pressing Enter after each:
  cd assignment_04
  python -m streamlit run dashboard/app.py
  If the terminal already shows a path ending in assignment_04, skip the cd
  line.

  3. The dashboard opens in your browser. Streamlit usually opens a new tab by
  itself. If it doesn't, the terminal prints something like:
  Local URL: http://localhost:8501
  Ctrl+click that link, or copy it into your browser. If this is your first time
  using Streamlit and it asks for an email, just press Enter.

  4. Keep the terminal open while you use it. The terminal runs the app, so
  closing it or pressing Ctrl+C there stops the dashboard. Don't worry about the
  findfont: 'Helvetica Neue' messages; they're harmless.

  If something goes wrong:
  - "No such file" or "File does not exist": the terminal isn't in the right
    folder. Type pwd to see where you are. You need to be in
    ...\comm4259\assignment_04.
  - "python is not recognized": the terminal isn't using Anaconda. Try opening
    the Anaconda Prompt instead and running the same two lines, starting with cd
    to your comm4259 folder.
  - The browser page goes blank or says "Connection error": the terminal was
    closed or stopped. Run the command again.

  Once it's open, start on Tab 1 (Data). Click Describe the dataset, then Set 
  target and positive class, and work through the tabs in order. Task B1 in the
  notebook walks you through it.

  Also remember to run the requirements.txt cell (cell 31) and then commit and
  push by hand if you haven't yet.
